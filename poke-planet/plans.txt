Algorithm Enhancement

FUNCTION chooseEnemyAction(battleState):

    availableActions = []

    ADD attack to availableActions

    IF enemy has heals AND enemy health is below maximum:
        ADD heal

    IF enemy is not already evading:
        ADD evade

    IF special cooldown is zero:
        ADD special

    FOR each action in availableActions:
        score action based on current battle state

        IF enemy health is critically low:
            increase heal score

        IF player health is low:
            increase attack score

        IF player attack is high:
            increase evade score

        IF special move creates a useful effect:
            increase special score

    RETURN action with highest score
